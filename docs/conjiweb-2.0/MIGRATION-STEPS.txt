Conjiweb 1.5 to 2.0 Migration Steps

Stage 1:
保留全部 1.5 文件，新增 omemo2 并行模块。

Stage 2:
登录后初始化：
  const omemo2 = OmemoCore.create()
  await omemo2.init(accountJid)

Stage 3:
发送 OMEMO：
  encryptedXml = await omemo2.encryptMessage(toJid, plaintext)

Stage 4:
接收 OMEMO：
  plaintext = await omemo2.decryptMessage(fromJid, stanzaXml)

Stage 5:
替换 placeholder：
  - DeviceManager.fetchDeviceList -> 真实 XMPP PubSub
  - BundleManager.fetchBundle -> 真实 XMPP PubSub
  - SessionManager encrypt/decrypt -> 真实 Signal session
  - OmemoStore localStorage -> IndexedDB 或原项目数据库

Stage 6:
测试：
  - Conjiweb -> Conversations
  - Conversations -> Conjiweb
  - 多设备
  - 新设备信任
  - 重启 identity 稳定
