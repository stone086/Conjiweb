# Contributing

## Development Setup
1. Clone repository.
2. Copy `.env.example` to `.env`.
3. Run services needed for local development.

## Branching
- Use small focused branches.
- Keep commit messages clear and scoped.

## Pull Requests
- Explain what changed and why.
- Include screenshots for UI changes.
- Mention migration/security/ops impact.

## Quality
- Run frontend build before opening PR.
- Add tests for backend behavior changes when possible.
- Update docs when commands/configs change.
